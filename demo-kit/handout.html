प्रामाणिक अभियांत्रिकी

वेळ का लागतो (५–१५ से.)?

मोफत tier वर काळजीपूर्वक vision विश्लेषणाची हीच खरी किंमत. स्क्रीनवर घुमते मराठी स्टेटस + लाइव्ह टाइमर — प्रतीक्षा कधीही गोठलेली दिसत नाही. आम्ही वेग लपवत नाही, प्रामाणिकपणे सांगतो.

AI चुकेल तर?

स्पष्ट नसलेला/आंब्याचा नसलेला फोटो → कमी खात्री + "जवळचा फोटो पाठवा" — खोटे निदान कधीच नाही. प्रत्येक field server-side व्हॅलिडेट होतो (severity/stage whitelist, confidence clamp).

नेट गेले तर?

शेवटचे यशस्वी निदान AsyncStorage वर जतन — result पान "ऑफलाइन" बॅनरसह कॅशेतून उघडते (खऱ्या नेट-अपयशावर चाचणी केलेले). इतिहास कधीही रिकामा नाही: नवीन खात्यावर ३ स्पष्टपणे चिन्हांकित "नमुना तपासणी" नमुने.

तंत्रज्ञान व खर्च

Stack: React Native (Expo SDK 54, expo-router) · TypeScript · Supabase (Postgres + Auth + Storage + Edge Functions, RLS) · Google Gemini vision + speech (मोफत tier) · expo-speech (मराठी TTS)

  • AI key कधीच app मध्ये नाही — सर्व कॉल server-side edge function द्वारे; 2-key failover + retry-backoff built in.
  • खर्च: Gemini मोफत tier + Supabase मोफत tier + Expo मोफत = प्रति निदान अपवादाच्या घटकाचा एक पैसा; शेतकऱ्यासाठी नेहमी मोफत.
  • पुढचे: median latency < ३ से. (इमेज डाउनस्केल + streaming), पूर्ण offline-first queue, कोकण outbreak map, e-NAM भाव सूचना.
